# ArboristPrepAI

Independent browser-local study diagnostic and review planner for Certified Arborist candidates.

The production build includes 15 original-study SEO pages, policy and support pages, a 19-URL sitemap, and IndexNow submission automation.

## Commands

- `npm test`
- `npm run dev`
- `npm run deploy`
- `npm run indexnow`

ArboristPrepAI is not affiliated with or endorsed by ISA. It does not reproduce official or recalled exam questions.
